# Midterm report

`main.tex` is the report. Its Part 1 tables are in this directory; the selected
Part 2 tables are in `tables/`. The report includes the Part 1 PCA figure from
`figures/`. `main.pdf` is the locally compiled draft. Review responsibilities
and the AI assistance disclosure before submission.

From the repository root, compile with `make report-pdf`. The selected Part 2
model is the uncalibrated HW3-style combined-text classifier described in
the report; the table values come from its saved execution. `writeup/build_tables.py` is historical code for the
former calibrated model and would overwrite the selected Part 2 tables; do not
run it for this report.
